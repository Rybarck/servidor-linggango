# Linggango RPG — pacote do servidor

- Minecraft 1.20.1
- Forge 47.4.20
- Modpack Linggango V6.6.4hotfix
- Mods de servidor preparados localmente: 368

Instale Java 17 no host. Baixe o instalador oficial Forge 1.20.1-47.4.20 e execute:

```bash
java -jar forge-1.20.1-47.4.20-installer.jar --installServer
```

Aceite a EULA alterando `eula=false` para `eula=true`. Os mods client-side removidos estão listados em `CLIENT_MODS_REMOVED.txt`.

A pasta completa do servidor, incluindo os JARs locais, está em:
`C:\Users\joaop\curseforge\minecraft\Instances\Guaíba RPG_\server`
